# Contributing

[简体中文](CONTRIBUTING.md) · **English**

Thank you for helping improve Tarot Pixel's documentation and user experience.

This repository accepts improvements to product documentation, tutorials, FAQs, and publicly shareable examples. Use the [feedback channels](SUPPORT.en.md) for software bugs and feature requests.

## Improve the documentation

1. For a small correction, submit a pull request explaining the problem readers encounter.
2. For larger structural changes, describe the goal in an Issue or Discussion first.
3. Write in Simplified Chinese or English and preserve the original identifiers for code, commands, and tools. Keep corresponding pages and language links in sync where possible.
4. Verify versions, installation links, and capabilities. Distinguish available features from ideas and measured results.
5. Check relative links, code blocks, and image rendering. Do not include local absolute paths or credentials.

## Share demos and examples

Only share designs, screenshots, and assets you have permission to publish. Record client, model, and plugin versions, along with viewport, font conditions, the initial result, and subsequent corrections. You can start by sharing a link and description in Discussions.

## Maintainer release checks

- The homepage, installation guide, and supported capabilities describe features consistently in both languages.
- Local documentation and image links work, and public entry points are accessible to their intended users.
- Issue forms open correctly, their labels exist, and discussion links work.
- Examples are sanitized and recording links can be opened publicly.
- Software fixes reference actual release versions. Documentation changes update both changelogs.
