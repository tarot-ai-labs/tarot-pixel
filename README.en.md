## Bring designs into your project

Tarot Pixel lets your agent look up layouts, styles, and images as needed, reuse your existing components, and revisit design details while refining the implementation.

> Use Tarot Pixel to implement this design: `<synced design link>`. Reuse our existing components and keep titles, prices, and buttons dynamic. Preview the page and compare it with the design to refine the details.

## What you can do

| Your task | What Tarot Pixel provides |
| --- | --- |
| Find a page or component | Design overviews, module previews, and layer search |
| Reproduce layout and styling | Dimensions, spacing, typography, colors, and hierarchy |
| Handle complex decoration | Single-layer and multi-layer composites |
| Implement different states | Module comparisons to use alongside business requirements |
| Check the result | Design screenshots and a local preview for comparison and refinement |
| Use design assets | Images and font subsets |

## Get started

1. **Enable the plugin.** Install and enable Tarot Pixel from the [Qoder marketplace](https://qoder.com/zh/marketplace/plugin?id=tarot-pixel).
2. **Sync a design.** Select frames, artboards, or layers in Figma or Sketch, run Tarot Pixel, and choose **Sync design**.
3. **Give the agent a task.** Share the complete link returned by the sync and describe what to build in your project.
