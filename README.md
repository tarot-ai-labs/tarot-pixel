## 把设计接进你的项目

Tarot Pixel 让 Agent 按需查阅设计稿的布局、样式和图片，复用项目已有组件完成实现，并在修改时回查设计细节。

> 使用 Tarot Pixel 实现这个设计：〈同步后的设计链接〉。复用项目现有组件，标题、价格和按钮支持动态内容。完成后预览页面，对照设计稿修正细节。

## 你可以用它做什么

| 你要做的事 | Tarot Pixel 提供的能力 |
| --- | --- |
| 找到页面或组件 | 设计概览、模块预览与图层搜索 |
| 还原布局与样式 | 尺寸、间距、字体、颜色与层级关系 |
| 处理复杂装饰 | 单图层或多图层合图 |
| 实现不同状态 | 比较模块差异，结合业务需求组织组件 |
| 检查实现效果 | 设计截图与本地预览，支持回查和修正 |
| 使用设计资源 | 图片资源与字体子集 |

## 开始使用

1. **启用插件。** 在 [Qoder 插件市场](https://qoder.com/zh/marketplace/plugin?id=tarot-pixel)安装并启用 Tarot Pixel。
2. **同步设计。** 在 Figma 或 Sketch 中选择目标画板或图层，运行 Tarot Pixel，点击“同步设计稿”。
3. **交给 Agent。** 将同步返回的完整链接和实现需求发送给 Agent，在当前项目中完成实现。
