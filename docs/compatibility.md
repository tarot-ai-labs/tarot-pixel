# 支持范围

**简体中文** · [English](en/compatibility.md)

[返回首页](../README.md) · [安装指南](installation.md)

本页描述当前本地 MCP 产品形态。文档配置示例通过 `latest` 使用 npm 最新发布的 Runtime；各设计工具插件独立发布，版本号无需一致。

## 接入方式

| 组件            | 当前说明                                                                                                          |
| --------------- | ----------------------------------------------------------------------------------------------------------------- |
| Qoder           | 可从 [Qoder 插件市场](https://qoder.com/zh/marketplace/plugin?id=tarot-pixel)安装 Tarot Pixel，也可以手动配置 MCP |
| 其他 MCP 客户端 | 可按 stdio MCP 协议接入；配置、资源读取和浏览器能力取决于客户端，未逐一承诺完整兼容性                             |
| Figma           | 提供公开插件入口，通过插件同步选中的 Frame 或图层                                                                 |
| Sketch          | 提供公开 ZIP，要求 Sketch 80.0 或更高版本                                                                         |
| 本地 View       | 随 Runtime 启动，用于浏览设计、图层与资源                                                                         |

## 当前提供的能力

- 设计、模块与节点浏览，文本和图层搜索。
- 布局、尺寸、间距、样式和相对位置查询。
- 分层 D2C 上下文与批量节点上下文。
- 节点定位图、设计截图、单节点和多节点合图。
- 模块差异分析、图片内容元数据和本地字体子集。

## 使用边界

- Agent 和 View 的读取、分析、渲染通过 MCP 提供；设计工具同步使用专用导入通道。
- 当前本地产品不包含原文探索版本中的通用 REST 查询接口、内置 Chat 视觉 Agent 或交互式 TUI。
- 节点定位图显示节点标注，不提供“上传任意图片后自动识别对应节点”的承诺。
- 模块差异辅助 Agent 理解多个画板，业务状态与交互规则仍需要需求说明。
- 设计源文件修改后需要重新同步；已导入的快照不会自动跟随源文件变化。
- 合图、截图和字体效果受到设计工具导出、本机字体、浏览器与视口条件影响。
- 浏览器查看实现、业务代码执行和测试依赖客户端与项目工具。

## 运行环境

Runtime 要求 Node.js 20.19.0 或更高版本。截图和合图需要可用的 Chrome、Chromium、Edge 或 Brave。本仓库尚未发布完整的操作系统与客户端组合验证矩阵；遇到环境差异，请在[问题反馈](https://github.com/tarot-ai-labs/tarot-pixel/issues/new?template=bug-report.yml)中填写操作系统和版本。
