# 视觉上下文

**简体中文** · [English](en/design-philosophy.md)

[返回首页](../README.md) · [开始使用](quick-start.md)

Tarot Pixel 把设计稿整理为 Agent 随时可以查阅的参考资料：从页面全貌到具体图层，从布局数值到视觉资源。

开发一个商品卡片时，Agent 可以先看整体，再查标题字号、按钮间距和背景图层；结合项目已有组件、价格数据和点击行为，完成实现。

- **按需查设计。** 先定位页面或模块，再读取当前任务需要的节点、样式和资源。
- **结合项目实现。** 复用组件和样式规范，让动态内容、业务状态与视觉效果一起工作。
- **持续回查修正。** 预览后发现偏差，回到对应设计节点查询并修改。

例如，复杂光效可以合成背景图片；标题、价格和按钮仍用代码实现，方便更新内容与处理交互。
