# 数据与隐私

[返回首页](../README.md) · [反馈指南](../SUPPORT.md)

## 本地数据

Tarot Pixel 的本地 Runtime 默认将设计数据、资源和渲染结果保存在当前用户的本机数据目录。完整 Runtime、View 和 MCP HTTP 服务绑定本机回环地址；设计工具通过专用导入通道同步数据。

本地运行不等于整个 AI 工作流的数据都留在本机。Coding Agent 读取的设计文本、样式、截图或资源，可能进入你所使用的客户端及模型服务。请结合设计工具、客户端、模型服务和所在组织的要求选择可处理的内容。

## 资源使用

生成的图片和字体需要保存到业务项目管理的目录后再引用。设计稿、字体、图片及其他素材的使用范围，以相应权利人或供应方的授权为准。

## 公开反馈

本仓库的 Issues 和 Discussions 是公开内容。提交时只保留定位问题所需的信息：

- 截图隐藏客户信息、内部项目名称和业务数据。
- 日志移除凭据、Token、账号信息与完整本地路径。
- 原始设计文件仅在确认可公开时提供，优先使用最小复现示例。

软件不会因为你打开本仓库而自动上传本地设计；用户反馈通过 GitHub 表单由你主动提交。
