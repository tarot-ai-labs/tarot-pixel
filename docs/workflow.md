# 使用流程与提示词

**简体中文** · [English](en/workflow.md)

[返回首页](../README.md) · [快速开始](quick-start.md)

同步设计后，将完整设计链接和目标页面或组件一起发送给 Agent。说明需要复用的组件、动态内容和交互要求，完成后预览并对照设计。

## 实现一个页面

```text
请使用 Tarot Pixel 实现这个设计：<完整设计链接>。
目标是「活动首页」，沿用当前项目的技术栈和组件规范。
按需读取布局、样式和图片，将资源保存到项目目录。
活动标题、价格、倒计时和按钮状态支持动态内容。
交互按项目需求与接口约定实现，完成后预览并对照设计稿修正。
```

## 修正一个局部

```text
继续核对这个设计：<完整设计链接>，目标是「商品卡片」。
按钮与价格间距偏大，背景装饰位置偏下。
请回查对应节点的布局和样式，保留业务逻辑，修正后再次预览。
```

## 实现多状态组件

```text
这个设计：<完整设计链接>，包含「可领取」「已领取」「已过期」三种状态。
请比较相关模块，结合项目的业务状态定义组织为一个组件。
复用共有结构，让文本、样式和交互随状态变化，并分别预览三个状态。
```

## 处理背景与动态内容

```text
请将这个卡片的复杂背景装饰按需合图。
标题、价格和按钮用代码实现，支持动态更新。
检查图片中已经包含的内容，避免重复渲染，并将资源保存到项目目录。
```
