# 使用流程与提示词

[返回首页](../README.md) · [快速开始](quick-start.md)

## 从设计到实现

1. **同步并核对。** 在设计工具中同步目标区域，在本地 View 确认模块完整、文字与资源正确。
2. **说明项目目标。** 提供完整设计链接、目标页面或组件、交互状态和需要复用的规范。
3. **逐层读取。** Agent 从概览定位模块，再读取相关节点的布局、样式和资源。
4. **选择实现方式。** 持续变化的文字和数据保留为代码；复杂装饰根据设计证据决定是否合图。
5. **运行与对照。** 在对应视口、字体和状态下比较页面，回查设计并修正。

页面运行和浏览器验证取决于客户端与项目工具。客户端缺少浏览器能力时，可以由开发者预览并指出偏差。

## 实现一个页面

```text
请使用 Tarot Pixel 实现这个设计：<完整设计链接>。
目标是「活动首页」模块，沿用当前项目的技术栈和组件规范。

先检查项目结构并定位设计模块，再按需获取布局、样式和资源。
活动标题、价格、倒计时和按钮状态需要保留为动态内容。
业务交互以已有需求和接口约定为准，缺失的信息不要从静态设计稿猜测。
生成的图片与字体存入项目管理的资源目录。
完成后运行项目，在设计对应的视口下对照并修正主要偏差。
```

## 修正一个局部

```text
继续核对这个设计：<完整设计链接>，目标是「商品卡片」。
当前页面的按钮与价格间距偏大，背景装饰位置偏下。
请定位对应节点，查询布局、相对位置和资源边界后修正。
保持已有业务逻辑，完成后在相同视口下再次对照。
```

## 实现多状态组件

```text
这个设计：<完整设计链接>，包含卡片的「可领取」「已领取」「已过期」状态。
请先查看相关模块并比较差异，再结合项目的业务状态定义组织为一个组件。
明确哪些结构共用、哪些文本、样式和交互随状态变化。
分别预览三个状态，并说明设计中未表达、仍需要需求补充的行为。
```

模块差异可提供线索，状态语义和交互规则需要业务需求补充。

## 处理背景与动态内容

```text
请检查这个卡片背景的组成，按需合成复杂装饰。
标题、价格、按钮文案以及后续会变化的数据保持可编辑。
检查已有图片中是否已经包含文字或构件，避免在页面中重复渲染。
将生成的资源保存到项目目录，并确认透明边缘和显示尺寸正确。
```

## 常用工具对应关系

以下为当前 MCP 工具名称。日常使用只需表达任务，具体参数以客户端列出的工具定义为准。

| 目的                 | 工具示例                                                                                    |
| -------------------- | ------------------------------------------------------------------------------------------- |
| 检查连接             | `server_status`、`design_list`                                                              |
| 看整体设计           | `design_get_overview`、`design_list_modules`                                                |
| 找到目标节点         | `design_search_nodes`、`design_get_node_map`、`design_get_module_context`                   |
| 查询布局与样式       | `design_get_d2c_context`、`design_get_d2c_context_batch`、`design_get_node_relative_offset` |
| 理解图片中已有的内容 | `design_get_node_image_meta`                                                                |
| 查看设计截图         | `design_get_node_screenshot`、`design_get_module_screenshot`                                |
| 生成实现资源         | `design_get_composite`、`design_get_multi_composite`                                        |
| 比较模块             | `design_diff_modules`                                                                       |
| 处理本地字体         | `font_registry_get`、`font_subset_local`                                                    |

节点定位图和设计截图用于取证；需要实现用的装饰图片时，使用合图工具。临时资源地址需要转存到项目后再引用，详见[常见问题](faq.md)。
